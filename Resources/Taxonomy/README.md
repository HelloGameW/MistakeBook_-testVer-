# 知识树资源（高中双视图归档）

`seed.json` 是 App 内置知识分类种子。生产装配通过 `Bundle.main.url(forResource: "seed", withExtension: "json", subdirectory: "Taxonomy")` 加载，并注入 `IntelligenceFactory.makeTaxonomySeedProvider(resourceURL:)`。测试中的 synthetic seed 仅用于验证树结构，不替代正式知识树内容。

当前种子：`highschool-1.0.0`，共 132 个节点（9 个学科根 + 板块 + 考点），覆盖语文、数学、英语、物理、化学、生物、历史、地理、思想政治九科，按《普通高中课程标准》知识体系组织。

## 双视图归档模型

归档结构按两种模式使用，但**记录只存在于一棵树中**：

| 模式 | 结构 | 性质 |
| --- | --- | --- |
| 知识板块 | `学科 → 板块 → 考点`（如 数学 → 解析几何 → 圆锥曲线） | 唯一分类树，**所有记录的真实归档位置**，也是自动分类的唯一目标 |
| 年级知识 | `年级/学期 → 科目 → 板块 → 考点`（如 高一·上学期 → 数学 → 集合） | 由考点节点的年级元数据**实时派生的浏览视图**，不产生第二份节点 |

### 为什么年级视图是投影而不是第二棵树

`TaxonomyNode` 契约（1.0.0，冻结）是单父树，`subjectID` 必须指向学科根，一个节点无法同时属于“数学”和“高一”两个根。若把年级做成真实的第二棵树：

1. 同一考点存在两份节点，一条记录只能归入其中一棵，按另一模式浏览时记录“消失”，数据碎片化；
2. `KeywordClassificationService` 把所有根节点当学科根参与关键词匹配，年级根（“高一”等常出现在试卷抬头）会与学科根竞争，导致候选分裂和误归档。

投影模型下，记录归档到板块树后，年级视图按元数据自动归位，两个模式看到的是同一批记录。

## 年级元数据约定

年级/学期信息存放在**考点节点的保留别名**中，前缀 `grade:`：

| 别名 | 含义 | 年级视图展示 |
| --- | --- | --- |
| `grade:g1s1` | 高一上学期 | 高一 · 上学期 |
| `grade:g1s2` | 高一下学期 | 高一 · 下学期 |
| `grade:g2s1` / `grade:g2s2` | 高二上 / 下学期 | 高二 · 上 / 下学期 |
| `grade:g1`、`grade:g2` | 高一 / 高二全年 | 自动展开到该年级两个学期 |
| `grade:g3` | 高三新授内容（种子默认未使用） | 高三组 |

规则：

- **只有考点（叶子）节点携带 `grade:` 别名**；板块节点不携带，其年级归属由子考点推导。
- 关键词分类不受影响：`KeywordClassificationService` 对题干做归一化后匹配，`grade:g1s1` 归一化为拉丁串 `gradeg1s1`，不会出现在自然语言题干中。
- 跨学期考点（如“随机事件与概率”）可同时带 `grade:g1s2` 和 `grade:g2s2`，会在两个学期组中出现。
- 高三组为**总复习投影**：覆盖全部学科与板块（一轮/二轮复习按板块推进），因此考点无需标注 `grade:g3`。
- 排课默认值按人教 A 版新课标的常见进度设定，学校/个人进度不同时，可在归档页节点编辑器中调整“学年归属”，或修改本文件。

### 默认排课映射（节选）

- 数学：集合/逻辑/不等式/函数/三角函数概念 高一上；解三角形/向量/复数/立体几何初步/统计/概率初步 高一下；空间向量/直线与圆/圆锥曲线/数列 高二上；导数/计数/随机变量分布/成对数据 高二下。
- 物理：运动学/相互作用/牛顿定律 高一上；抛体与圆周/万有引力/功和能 高一下；动量/振动与波/静电场/电路/光学 高二上；磁场/电磁感应/交变电流/热学/原子 高二下。
- 化学：计量/离子反应/氧化还原/金属 高一上；非金属/结构与周期律/反应与能量初步/有机初步 高一下；速率平衡/水溶液/电化学 高二上；结构深入/有机深入 高二下。
- 生物：分子组成/细胞结构 高一上；代谢/细胞历程/遗传与进化 高一下～高二上；稳态与调节 高二上；生态/生物技术 高二下。
- 语文/英语：能力主线（阅读、写作、听力等）标注为高一、高二全年。
- 历史：中外历史纲要(上)内容 高一上，纲要(下)内容 高一下；地理、政治同理按必修/选择性必修进度。

## 节点 ID 约定

- 学科根：`chinese`、`math`、`english`、`physics`、`chemistry`、`biology`、`history`、`geography`、`civics`（`civics` 学科名为“思想政治”，别名保留“道德与法治”以兼容初中表述）。
- 板块/考点：`<学科>/<板块>[/<考点>]`，层级最多三层。记录关联的是稳定 ID，改名或调整别名不影响既有归档。

## 别名与自动分类

每个考点的 `aliases` 是关键词分类（`KeywordClassificationService`）的命中依据，收录了该考点的常见题面词汇。维护约定：

- 保留别名 ≥ 2 个字符（单字词会被分类器忽略）；
- `grade:` 前缀为保留前缀，请勿用于普通别名；
- 用户在归档页修改过的字段会记录在 `userModifiedFields`，后续种子升级时需保留这些字段（该合并逻辑尚未在 `LocalAppService` 中实现，属后续工作）。

## 迁移说明

- `LocalAppService` 仅在本地知识树为空时载入种子；替换 `seed.json` 对全新安装生效。
- 已使用旧示例种子（`example-1.0.0`）的存量安装不会自动迁移：旧节点 ID（如 `math/algebra`）与新树不同。存量迁移需要实现“种子升级合并”（按 `seedVersion` 比对、保留 `userModifiedFields` 字段、新树补齐缺失节点），并处理旧 ID → 新 ID 的记录重指向，属后续版本工作。
